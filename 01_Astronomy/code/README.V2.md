# Black Hole Simulator V2

Interactive black hole simulator that calculates the Schwarzschild radius using real-world NASA data. Compare stellar, intermediate and supermassive black holes, simulate astronomical objects, and create your own custom black holes.

## Features
- Interactive menu with 5 options
- Simulate astronomical objects (Earth, Mars, Sirius, Polaris...)
- Explore 9 real black holes classified by category (Stellar, Intermediate, Supermassive)
- Compare any two black holes with size ratio calculation
- Create custom black holes with automatic classification
- Schwarzschild radius calculation using real NASA data

## Data
- 9 confirmed black holes: GaiaBH3, Cygnus X-1, IL Lupi, Messier 15, HLX-1, GCIRS 13E, Sagittarius A*, Phoenix A, NGC 4889
- 7 astronomical objects: Earth, Mercury, Mars, Betelgeuse, Sirius, Alpha Cephei, Polaris
- All masses in solar masses (M☉)

## Classification
- Stellar: < 100 M☉
- Intermediate: 100 - 100,000 M☉
- Supermassive: > 100,000 M☉

## Technical Stack
- Python 3.x
- Nested dictionaries (3 levels)
- Interactive input system with while loop
- Schwarzschild radius formula: r = 2GM/c²
