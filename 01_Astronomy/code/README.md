# Black Hole Simulator V1

Black hole simulator that calculates the Schwarzschild radius using real-world data (NASA). Comparison of stellar and supermassive black holes, visualised using Matplotlib on a logarithmic scale.

## Features
- Schwarzschild radius calculation for 9 real black holes
- Stellar vs Supermassive comparison
- Logarithmic scale visualisation with Matplotlib

## Data Sources
- NASA confirmed black hole catalog
- Mass values in solar masses (M☉)

## Black Holes Included
- **Stellar:** Sun, Cygnus X-1, GRO J1655-40, V404 Cygni
- **Supermassive:** Sagittarius A*, M87*, NGC 4889, TON 618, Phoenix A

## Requirements
- Python 3.x
- Matplotlib
